# DSH 0.2.2-alpha.2 desktop compatibility

Rebased against the exact official npm packages with pi-ai 1.3.0. Twenty-one core targets preserve Desktop session lifecycle/deletion, MP4 transport and preview, old stored-log compatibility and progressive tool presentation while leaving the official lifetime persistence lock unchanged. Artifact and marketplace client adapters have separate manifests.

The Native/PTC executors own dispatch. Progressive presentation filters their declarations without bypassing scoped step admission; nested calls retain tool sets, lifecycle and images. Four plugin patches reproduce the adaptations from the exact Git commits in runtime/dependencies.json, with per-file hashes and patch hashes. The Include package owns the YAML expression dialect. Scheduling is promoted to the built-in Host service; the obsolete optional-bundle activation is backed up during profile migration.

Mac/Windows/Ubuntu use the pinned Node 24.15.0 runtime. Kylin V10 old-world compatibility is a separately tested platform port and must disclose any Node version exception and unavailable target-device validation.
